# Práctica 4 — Integración Continua

Programa **Hola Mundo** en JavaScript con un workflow de GitHub Actions
(`.github/workflows/alerta.yml`) que, en cada push a la rama `main`,
ejecuta el programa y envía una notificación a
[ntfy.sh/devops-itla](https://ntfy.sh/devops-itla).

## Ejecutar localmente

```bash
node index.js
```
